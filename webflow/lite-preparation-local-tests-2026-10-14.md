## Findings and change

The original 41 tests, `npm run check` and `npm run check:dist` passed before
changes. A new transition regression failed against maintained source and each
exact committed v0.2.6 JavaScript delivery: unminified dist, minified dist and
self-contained Webflow Embed.

Reproduction: initialise Tablet collapse at a simulated 820px, open with a 40ms
transition, then expand to 1280px before the timer finishes. State immediately
becomes `expanded`, but the pending timer later overwrites it with `open` and
sets the hidden trigger's `aria-expanded` to true. The closing version is more
serious: expanding during a 40ms close later becomes `closed`, hides the panel
from accessibility and sets `inert`, despite desktop expansion. The closing
regression also checks restoration of existing overflow/padding styles.

`src/navbar-light.js` now cancels the pending state timer and pending first-link
focus request when switching to expanded mode or resetting into collapsed mode.
No layout, icon styling, API, content, class namespace or release version changed.
Source: `tests/runtime-delivery.test.js`, both transition regression tests;
`NavbarLight.onBreakpointChange` in maintained source.

## Automated evidence

`tests/runtime-delivery.test.js` loads source (normalised to classic JavaScript),
exact committed `dist/navbar-light.js`, `dist/navbar-light.min.js`, and the
script/style extracted from `webflow/navbar-light-embed.html`. Each delivery
receives the same native details/summary fixture and its corresponding CSS.
Installed jsdom supplies DOM state and computed styles; the harness explicitly
mocks media queries and CSS.supports. It supplies no browser layout engine.

Across four deliveries, the added tests cover:

- 260 initialisation cases: five collapse choices × 13 widths (320, 393, 478,
  479, 480, 766, 767, 768, 990, 991, 992, 1280 and 2060px). Assertions cover
  collapse state, ARIA and inert; a further open-menu resize tests expansion and
  reset on returning to mobile. These are simulated media-query boundaries,
  not rendered screen-size or overflow evidence.
- 140 open/close cases: five layouts × seven motions, including custom, per
  delivery. Assertions cover lifecycle completion, panel ARIA/inert, first-link
  focus, expected scroll lock, synthetic Escape and trigger focus restoration.
  Custom timing is checked without a GSAP integration.
- Nested and outer Escape focus restoration; backdrop, link and outside closing;
  disabled link/outside closing; duplicate init prevention and repeat destroy.
- 96 icon calculations: two/three lines × 1–4px bar height × 5/7/9px gap, per
  delivery. These prove the auto-shift token calculation only. They do not prove
  transformed line centres, visual quality or any pixel-density rendering.
- All seven motion modes with mocked reduced motion: JavaScript waits are zero.
  This does not verify CSS media-query rendering or an actual OS setting.
- CSS-only Always fallback with no runtime evaluated: native `open` reveals the
  adjacent sibling panel, closes it again and preserves native link content.
  This does not prove physical Enter/Space activation, other CSS breakpoints or
  wrapped-trigger fallback. No enhanced Escape/ARIA behavior is claimed without JS.

The pre-existing tests also cover loader SRI, exact pinned URLs, load failure
reporting/content preservation, source CSS rules and direct-file demo startup.

Final `npm test`: 73 tests, 67 passes, zero unexpected failures, six TODO failures

## Fresh-build verification without changing a release

`npm run test:built` uses `scripts/check-built-runtime.mjs` to run
`scripts/build-all.mjs`, then the runtime, dist and demo
suites against the freshly generated bytes. It runs all transition regressions
as mandatory checks. It restores all 12 pre-build generated files in `finally`,
including all four maps, Canvas Embed, CDN loader and demo browser script, on
normal success or test/build failure. A forced process termination can interrupt
restoration; use git readback before committing after an interrupted run.

The fixed temporary build passed 36/36 tests, zero TODOs. Generated-artifact tests
also verified locally generated loader SRI and version markers. This is an
unreleased build of maintained source, not a correction to immutable v0.2.6.
`git diff --exit-code` over all generated paths confirmed exact restoration.
Do not copy its transient v0.2.6 loader/SRI into Webflow: a separately authorised
new semantic release is needed before distribution of the fix.

After the source fix, `check:dist` is expected to fail because source deliberately
differs from immutable v0.2.6. It passed at baseline. README §Local development
explicitly allows this between releases. Do not follow its generic rebuild/commit
suggestion by replacing v0.2.6 bytes. The fresh-build test is the local candidate
build gate; a future release must restore ordinary distribution parity at its
new version. Source: README §Local development and SCOPE S-07 / D-002.
