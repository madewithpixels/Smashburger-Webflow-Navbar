## Findings and change

The original 41 tests, `npm run check` and `npm run check:dist` passed before
changes. A new transition regression failed against maintained source and each
exact committed v0.2.6 JavaScript delivery: unminified dist, minified dist and
self-contained Webflow Embed.

Reproduction: initialise Tablet collapse at a simulated 820px, open with a 40ms
transition, then expand to 1280px before the timer finishes. State immediately
becomes `expanded`, but the pending timer later overwrites it with `open` and
sets the hidden trigger's `aria-expanded` to true. The closing version is more
serious: expanding during a 40ms close later becomes `closed`, hides the panel
from accessibility and sets `inert`, despite desktop expansion. The closing
regression also checks restoration of existing overflow/padding styles.

`src/navbar-light.js` now cancels the pending state timer and pending first-link
focus request when switching to expanded mode or resetting into collapsed mode.
No layout, icon styling, API, content, class namespace or release version changed.
Source: `tests/runtime-delivery.test.js`, both transition regression tests;
`NavbarLight.onBreakpointChange` in maintained source.
